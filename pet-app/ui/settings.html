FairyPet 设置 改动即时生效

外观

整个桌宠等比缩放，窗口同步（右下角为锚点）。范围 50%–200%。

几何（fairy-lab 校准值）

单位 = SVG 用户单位（viewBox 240）。靛蓝环带外缘 / 尖齿参数会重建尖齿 path。

动效

呼吸幅度由内向外递减（深眼 ±9.9% → 白环 ±4.1%），各环带相位阶梯 96ms，均按实测锁定。

台词

实际等待 = 设定值 ~ 设定值+35s 随机。台词池与语气见 ui/lines.json。

语音（豆包语音合成）

语音开关
测试文本
需在火山引擎开通「豆包语音合成大模型」并获取密钥；密钥只保存在本机配置文件。 用声音复刻音色时，资源 ID 选 seed-icl-2.0，音色 ID 填复刻生成的 ID。 语音开关关闭后完全不调用合成接口（不消耗额度），只显示文字气泡。 开启语音时桌宠会闭眼说话，说完恢复。
